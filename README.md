# 📖 Project Organization

Each module contains one or more standalone Spring Boot applications.

Example:

```
03-hibernate-and-spring-boot-data-jpa/
│
├── crud-demo/
├── one-to-one-mapping/
├── one-to-many-mapping/
├── many-to-many-mapping/
├── pagination-sorting/
└── specifications/
```

Each application is generated independently using Spring Initializr and has its own:

- `pom.xml`
- `src/`
- `.mvn/`
- `mvnw`
- `application.properties`
- `README.md`
